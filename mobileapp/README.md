# XoXoPay Mobile App

React Native (Expo) application for XoXoPay social payments.

## Features

- Social payments feed with likes and comments.
- Username registration and profile management.
- Offline transaction queue with replay on reconnect.
- NFC tap-to-pay.
- Mnemonic backup with verification quiz.
- Biometric unlock.
- Cross-chain funding via Allbridge.
- SDP deep links (`xoxopay://`).
- Merchant mode with QR codes and payment options.

## Getting Started

```bash
npm install
npm start
```

## Testing

npm test
